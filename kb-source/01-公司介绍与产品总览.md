# 云帆科技公司介绍与产品总览

## 公司简介

云帆科技（CloudSail Technology）成立于 2016 年，总部位于杭州，是一家专注于智能物联（AIoT）的国家级高新技术企业。公司为连锁零售、智慧仓储、智能制造等行业的企业客户提供"智能硬件 + 云平台"一体化解决方案，累计服务企业客户超过 3,200 家，部署智能终端超过 18 万台。

## 产品线介绍

### CloudSail G3 智能网关

G3 是面向连锁门店与小型仓储的边缘智能网关，支持 Wi-Fi、以太网、4G 三种上行方式，下行支持 Zigbee 3.0 与 RS-485，可接入最多 64 个子设备。标准版单价 1,299 元，含 1 年云平台基础版服务。

### CloudSail G3 Pro 智能网关

G3 Pro 面向中大型仓储与工厂，在 G3 基础上增加双频 Wi-Fi、POE 供电与本地断网续传（内置 32GB 存储），可接入最多 256 个子设备，支持双机热备。单价 2,499 元。

### S100 环境传感器

S100 集成温度、湿度、光照与人体感应四合一传感，Zigbee 3.0 协议，电池供电续航 2 年，单价 199 元，常与 G3 网关配套部署。

### CloudSail OS 云平台

CloudSail OS 是设备管理与数据分析云平台。基础版免费（单账号最多 10 台设备、30 天数据留存）；专业版 599 元/年/门店，支持不限设备数量、数据留存 2 年、开放 API 与数据大屏；企业版按项目报价，支持私有化部署与专属客户成功经理。
